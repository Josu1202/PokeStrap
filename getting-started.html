Comenzando con PokeStrap

Aprende a instalar y usar PokeStrap para construir interfaces inspiradas en el mundo Pokémon.

Instalación

Agrega PokeStrap a tu proyecto para comenzar a diseñar.


npm install pokestrap

Uso básico

Incluye los archivos principales en tu documento HTML.


<link rel="stylesheet" href="assets/css/main.css">
<script src="assets/js/main.js"></script>

Conceptos principales

Componentes

Elementos reutilizables como botones, tarjetas y formularios inspirados en entrenadores y batallas.

Layout

Estructura flexible para organizar tu contenido como una Pokédex.

Utilities

Clases rápidas para modificar estilos sin esfuerzo.

Primer ejemplo

Un botón básico:


<button>Capturar Pokémon</button>
