Getting Started

Aprende a instalar y utilizar PokeStrap para construir interfaces modernas, consistentes y reutilizables.

Instalación

Puedes integrar PokeStrap en tu proyecto utilizando archivos locales o mediante un enlace directo al CSS.

Uso local

<link rel="stylesheet" href="PokeStrap_Framework/dist/css/pokestrap.css">

Instalación con npm

npm install pokestrap

Uso básico

Una vez añadido el CSS, puedes comenzar a utilizar las clases del framework directamente en tu HTML. 

<body class="pk-app">
  <button class="pk-btn pk-btn-primary">Acción</button>
</body>

Conceptos principales

Componentes

Elementos reutilizables como botones, cards y formularios.

Layout

Estructuras que organizan el contenido de la interfaz.

Utilities

Clases rápidas para modificar estilos sin escribir CSS adicional.
