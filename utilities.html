Utilities

Las utilities permiten aplicar estilos rápidamente mediante clases predefinidas sin necesidad de escribir CSS adicional.

¿Qué son las utilities?

Son clases diseñadas para modificar propiedades específicas como colores, espaciado, alineación o tipografía. Se utilizan directamente en el HTML para acelerar el desarrollo.

Categorías

Colores

Controla colores de texto y fondos usando variables del sistema.

Ajusta tamaños, jerarquía y estilos de texto.
