Grid System

El sistema de grid de PokeStrap permite crear estructuras responsivas usando filas y columnas basadas en un sistema de 12 columnas.

Layout Docs

Rejilla responsive

Usa .row para crear filas y .col-* para definir el ancho de cada columna según el tamaño de pantalla.

Ver grid

Estructura básica

Una grilla se construye con un contenedor, una fila y columnas.

col-md-4
col-md-4
col-md-4 
<div class="container">
  <div class="row">
    <div class="col-12 col-md-4">Columna 1</div>
    <div class="col-12 col-md-4">Columna 2</div>
    <div class="col-12 col-md-4">Columna 3</div>
  </div>
</div>
