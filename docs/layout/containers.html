Containers

Los contenedores permiten centrar el contenido y controlar su ancho máximo dentro de la página.

Layout Docs

Estructura base del contenido

El build Water se utiliza para documentar el sistema de layout, manteniendo una apariencia limpia y técnica.

Ver contenedores

Container

La clase .container centra el contenido y limita su ancho máximo según el tamaño de pantalla.

.container 
<div class="container">
  Contenido centrado con ancho máximo
</div>

Container fluid

La clase .container-fluid ocupa todo el ancho disponible, manteniendo un padding lateral.

.container-fluid 
<div class="container-fluid">
  Contenido de ancho completo
</div>

Comparación visual

Usa .container cuando quieras contenido centrado y controlado. Usa .container-fluid cuando necesites ocupar todo el ancho.

Container centrado
Container fluid 
<div class="container">...</div>
<div class="container-fluid">...</div>

Uso recomendado

Para la mayoría de secciones de documentación o páginas comunes, usa .container. Para barras, fondos extendidos o bloques de ancho completo, usa .container-fluid.
