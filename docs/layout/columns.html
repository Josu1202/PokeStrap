Columns

Las columnas permiten controlar cuánto espacio ocupa cada elemento dentro de una fila. PokeStrap usa un sistema de 12 columnas compatible con breakpoints.

Layout Docs

Columnas flexibles y responsivas

Combina clases como .col-12, .col-md-6 y .col-lg-4 para adaptar el diseño según el tamaño de pantalla.

Ver columnas

Columnas fijas

Las clases .col-* definen el ancho de una columna usando el sistema de 12 partes.

col-10
col-3
col-9
col-4

  <div class="col-4">Columna 4</div>
  <div class="col-8">Columna 8</div>
</div>

Columnas iguales

La clase .col distribuye automáticamente el espacio disponible entre los elementos dentro de la fila.
