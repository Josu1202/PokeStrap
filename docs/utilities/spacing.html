Spacing

Las utilidades de spacing permiten aplicar márgenes y paddings rápidamente usando clases cortas inspiradas en Bootstrap.

Utility Docs

Espaciado rápido y consistente

Usa clases como .m-4, .mt-6, .p-3, .px-4 o .py-2 para controlar separación sin CSS adicional.

Ver ejemplos

Padding

Las clases .p-* aplican padding en todos los lados.

.p-2
.p-4
.p-8 
<div class="p-2">Padding 2</div>
<div class="p-4">Padding 4</div>
<div class="p-8">Padding 8</div>

Padding por eje

Usa .px-* para padding horizontal y .py-* para padding vertical.

.px-6 .py-2
.px-2 .py-6 
<div class="px-6 py-2">Padding horizontal amplio</div>
<div class="px-2 py-6">Padding vertical amplio</div>

Margin

Las clases .m-* aplican margin en todos los lados.

.m-2
.m-4
.m-6
<div class="m-2">Margin 2</div>
<div class="m-4">Margin 4</div>
<div class="m-6">Margin 6</div>

Margin por dirección

Usa .mt-*, .mb-*, .ms-* y .me-* para controlar direcciones específicas.

Elemento con .mb-4
Elemento con .mt-6 
<div class="mb-4">Margin bottom 4</div>
<div class="mt-6">Margin top 6</div>

Margin automático

Las clases .m-auto y .mx-auto ayudan a centrar elementos.

.w-50 .mx-auto 
<div class="w-50 mx-auto">
  Elemento centrado
</div>

Referencia rápida

Clase Uso
.m-4 Margin en todos los lados.
.mt-4 Margin superior.
.mb-4 Margin inferior.
.p-4 Padding en todos los lados.
.px-4 Padding horizontal.
.py-4 Padding vertical. 
<div class="p-4 mb-6">
  Caja con padding y separación inferior
</div>
