Typography

Las utilidades tipográficas permiten controlar tamaño, peso, alineación, transformación y comportamiento del texto sin escribir CSS adicional.

Utility Docs

Texto flexible y expresivo

Usa clases como .fs-lg, .fw-bold, .text-center y .text-uppercase para modificar texto rápidamente.

Ver tipografía

Tamaños de fuente

Las clases .fs-* permiten cambiar el tamaño del texto.

Texto pequeño con .fs-sm

Texto base con .fs-md

Texto grande con .fs-lg

Texto extra grande con .fs-xl

Texto destacado con .fs-2xl

Título visual con .fs-3xl

<p class="fs-lg">Texto grande</p>
<p class="fs-2xl fw-bold">Texto destacado</p>

Clases tipográficas base

PokeStrap también incluye clases base para títulos y párrafos.

.pk-title-1

.pk-title-2

.pk-title-3

.pk-lead para texto introductorio o destacado.

.pk-text para párrafos normales dentro del framework.

.pk-small para texto secundario o notas breves.

<h1 class="pk-title-1">Título principal</h1>
<p class="pk-lead">Texto introductorio</p>
<p class="pk-text">Párrafo normal</p>

Decoración y truncado

Las clases .text-decoration-none y .text-truncate ayudan a controlar enlaces y textos largos.

Enlace sin subrayado

Este es un texto demasiado largo que será truncado con puntos suspensivos. 

<a href="#" class="text-decoration-none">
  Enlace sin subrayado
</a>

<p class="text-truncate">
  Texto demasiado largo...
</p>
