Shadows

Las utilidades de sombras permiten agregar profundidad visual a tarjetas, botones, badges, contenedores y elementos destacados.

Utility Docs

Profundidad visual rápida

Usa clases como .shadow-sm, .shadow-md, .shadow-lg y .shadow-none para controlar elevación.

Ver sombras

Escala de sombras

PokeStrap incluye diferentes niveles de sombra para crear jerarquía visual.

.shadow-sm

Sombra ligera

.shadow-md

Sombra media

.shadow-lg

Sombra alta

<div class="shadow-sm">Sombra ligera</div>
<div class="shadow-md">Sombra media</div>
<div class="shadow-lg">Sombra alta</div>

Eliminar sombras

La clase .shadow-none elimina cualquier sombra aplicada al elemento.

Caja con .shadow-lg
Caja con .shadow-none 
<div class="shadow-none">
  Sin sombra
</div>

Cards elevadas

Las sombras se combinan muy bien con .pk-card para crear bloques destacados.

Medium

Card con shadow-md

Útil para cards normales con un poco de elevación.

Large

Card con shadow-lg

Ideal para contenido importante o bloques destacados. 

<div class="pk-card shadow-md">
  <div class="pk-card-body">Card elevada</div>
</div>

<div class="pk-card shadow-lg">
  <div class="pk-card-body">Card destacada</div>
</div>

Sombras en botones

Puedes usar sombras para que una acción importante tenga más presencia visual. 

<button class="pk-btn pk-btn-primary shadow-md">
  Botón destacado
</button>

Sombras con badges

También puedes aplicar sombras pequeñas a badges o etiquetas visuales.

Electric Primary Dark 
<span class="pk-badge pk-badge-warning shadow-md rounded-pill">
  Electric
</span>

Referencia rápida

Clase Descripción
.shadow-none Elimina la sombra del elemento.
.shadow-sm Aplica una sombra ligera.
.shadow-md Aplica una sombra media.
.shadow-lg Aplica una sombra grande. 
<div class="shadow-lg rounded-lg p-4">
  Elemento elevado
</div>
