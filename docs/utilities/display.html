Display

Las utilidades display permiten controlar cómo se muestran los elementos: bloque, inline, flex, grid u ocultos según el tamaño de pantalla.

Utility Docs

Control visual rápido

Usa clases como .d-block, .d-none, .d-flex y variantes responsive como .d-md-block.

Ver display

Display básico

Las clases .d-* cambian el comportamiento visual del elemento.

.d-block ocupa todo el ancho disponible
.d-inline .d-inline-block 
<div class="d-block">Bloque</div>
<span class="d-inline">Inline</span>
<span class="d-inline-block">Inline block</span>

Ocultar elementos

La clase .d-none oculta un elemento completamente.

El siguiente elemento existe en el HTML, pero está oculto con .d-none.
Este contenido no se muestra.
Este contenido sí se muestra. 
<div class="d-none">
  Este contenido está oculto
</div>

Display responsive

Puedes mostrar u ocultar elementos según el breakpoint.

Cambia el ancho del navegador para ver el comportamiento.
Visible solo en móvil: .d-block .d-md-none
Visible desde pantallas medianas: .d-none .d-md-block 
<div class="d-block d-md-none">
  Visible solo en móvil
</div>

<div class="d-none d-md-block">
  Visible desde md
</div>

Casos comunes

Un uso frecuente es tener botones o mensajes distintos según el tamaño de pantalla.

Vista escritorio 
<div class="d-block d-lg-none">
  Botón para móvil
</div>

<div class="d-none d-lg-flex">
  Contenido para escritorio
</div>

Referencia rápida

Clase Descripción
.d-none Oculta el elemento.
.d-block Muestra el elemento como bloque.
.d-inline Muestra el elemento en línea.
.d-inline-block Muestra el elemento en línea con propiedades de bloque.
.d-flex Activa un contenedor flex.
.d-md-none Oculta desde pantallas medianas.
.d-md-block Muestra como bloque desde pantallas medianas. 
<div class="d-none d-md-block">
  Visible desde pantallas medianas
</div>
