Electric Build

Colors

Las utilidades de color permiten aplicar rápidamente fondos, textos y combinaciones visuales usando la paleta activa del build Electric.

Utility Docs

Colores rápidos para interfaces vivas

Usa clases como .bg-primary, .text-accent y .text-bg-warning para cambiar la apariencia sin escribir CSS adicional.

Ver colores

Fondos

Las clases .bg-* aplican colores de fondo.

bg-primary
bg-secondary
bg-accent
bg-success
bg-danger
bg-info
<div class="bg-primary text-black p-4">
  Fondo primary
</div>

Texto

Las clases .text-* cambian el color del texto.

Texto primary

Texto secondary

Texto accent

Texto success

Texto danger

Texto info

<p class="text-primary fw-bold">Texto primary</p>
<p class="text-accent">Texto accent</p>

Text background

Las clases .text-bg-* combinan color de fondo y color de texto.

text-bg-primary text-bg-secondary text-bg-warning text-bg-dark 
<span class="text-bg-primary">Primary</span>
<span class="text-bg-warning">Warning</span>

Escala de grises

También puedes usar fondos y textos con escala de grises.

bg-gray-100
bg-gray-300
bg-gray-600
bg-gray-900
<div class="bg-gray-100">Gray 100</div>
<div class="bg-gray-900 text-white">Gray 900</div>
