Tables

Las tablas de PokeStrap permiten presentar información tabular de forma clara, ordenada y compatible con variantes como bordes, hover y filas alternadas.

Component Docs

Tablas limpias y reutilizables

Usa tablas para documentar datos, listas, registros o comparaciones dentro de interfaces administrativas y páginas de documentación.

Ver variantes

Tabla básica

Para crear una tabla base, usa la clase .pk-table.

Pokémon Tipo Región
Bulbasaur Grass / Poison Kanto
Chikorita Grass Johto
Treecko Grass Hoenn 
<table class="pk-table">
  <thead>
    <tr>
      <th>Pokémon</th>
      <th>Tipo</th>
      <th>Región</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Bulbasaur</td>
      <td>Grass / Poison</td>
      <td>Kanto</td>
    </tr>
  </tbody>
</table>

Tabla con bordes

Agrega .pk-table-bordered para mostrar bordes en todas las celdas.

Componente Clase Disponible
Botones .pk-btn Sí
Cards .pk-card Sí
Alertas .pk-alert Sí 
<table class="pk-table pk-table-bordered">
  ...
</table>

Tabla con hover

Agrega .pk-table-hover para resaltar filas al pasar el cursor.

Tabla striped

Agrega .pk-table-striped para alternar el fondo de las filas.

Clase Uso
.pk-table Aplica el estilo base de tabla.
.pk-table-bordered Agrega bordes a las celdas.
.pk-table-hover Resalta filas al pasar el cursor.
.pk-table-striped Alterna el fondo de las filas. 
<table class="pk-table pk-table-striped">
  ...
</table>
