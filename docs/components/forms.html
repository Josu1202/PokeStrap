Forms

Los formularios de PokeStrap permiten estilizar inputs, selects, textareas, checkboxes y estados de validación de manera consistente.

Component Docs

Formularios claros y reutilizables

Esta página muestra cómo combinar campos, labels, validación y botones usando el build Grass de PokeStrap.

Explorar validación

Formulario básico

Usa .pk-form-group, .pk-label y .pk-input para crear campos de texto. 

<div class="pk-form-group">
  <label class="pk-label" for="name">Nombre</label>
  <input class="pk-input" id="name" type="text" placeholder="Ash Ketchum">
</div>

Select y textarea

PokeStrap también incluye estilos para listas desplegables y áreas de texto. 

<select class="pk-select">
  <option>Kanto</option>
  <option>Johto</option>
</select>

<textarea class="pk-textarea" placeholder="Mensaje"></textarea>

Checkbox

La clase .pk-checkbox permite aplicar el color principal del framework al control de selección. 

<label class="d-flex align-items-center">
  <input class="pk-checkbox me-2" type="checkbox" checked>
  Acepto recibir actualizaciones
</label>

Estados de validación

Usa .pk-is-valid y .pk-is-invalid para mostrar retroalimentación visual en los campos. 

<input class="pk-input pk-is-valid" type="text">
<input class="pk-input pk-is-invalid" type="text">

Formulario completo

Puedes combinar layout, forms, botones y alertas para construir formularios completos.

Formulario listo para integrarse en una interfaz responsiva.

  <div class="col-12 col-md-6">

  <div class="col-12 col-md-6">
    <select class="pk-select">...</select>
  </div>

<button class="pk-btn pk-btn-primary">Guardar</button>
