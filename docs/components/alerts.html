Alerts

Las alertas permiten mostrar mensajes contextuales al usuario como éxito, error, advertencia o información.

Component Docs

Feedback visual con estilo

Las alertas mantienen la estructura base, pero adoptan colores del build Grass.

Explorar alertas

Alerta básica

Las alertas utilizan la clase .pk-alert junto con una variante.

Esta es una alerta básica. 
<div class="pk-alert pk-alert-primary">
  Esta es una alerta básica.
</div>

Tipos de alertas

Puedes usar diferentes variantes según el contexto.

Operación exitosa
Error crítico
Advertencia importante
Información útil
<div class="pk-alert pk-alert-success">Éxito</div>
<div class="pk-alert pk-alert-danger">Error</div>
<div class="pk-alert pk-alert-warning">Advertencia</div>
<div class="pk-alert pk-alert-info">Info</div>

Alertas con contenido

Puedes incluir títulos, enlaces y otros elementos.

¡Éxito! Tu acción se ha completado correctamente. 
<div class="pk-alert pk-alert-success">
  <strong>¡Éxito!</strong> Acción completada.
</div>

Combinación con utilidades

Las alertas pueden combinarse con utilidades de espaciado y sombras.

Alerta con utilidades aplicadas 
<div class="pk-alert pk-alert-success shadow-md rounded-pill">
  Alerta personalizada
</div>
