Grass Build

Buttons

Esta página utiliza el build pokestrap-grass.css, por lo que los componentes mantienen las mismas clases, pero adoptan una paleta tipo planta.

Grass Theme

Misma estructura, nueva identidad visual

El framework conserva clases como .pk-btn, .pk-btn-primary y .pk-card, pero ahora sus colores principales se generan desde la configuración Grass.

Explorar botones

Botón base

Todo botón parte de la clase .pk-btn. Luego se agrega una variante de color como .pk-btn-primary. 

<button class="pk-btn pk-btn-primary">
  Primary Button
</button>

Variantes solid

Las variantes solid usan los colores principales del build Grass. 

<button class="pk-btn pk-btn-primary">Primary</button>
<button class="pk-btn pk-btn-secondary">Secondary</button>
<button class="pk-btn pk-btn-accent">Accent</button>
<button class="pk-btn pk-btn-success">Success</button>

Variantes outline

Las variantes outline mantienen fondo transparente y borde temático. 

<button class="pk-btn pk-btn-outline-primary">Primary</button>
<button class="pk-btn pk-btn-outline-accent">Accent</button>
<button class="pk-btn pk-btn-outline-success">Success</button>

Tamaños

PokeStrap incluye tres tamaños principales: small, default y large. 

<button class="pk-btn pk-btn-sm pk-btn-primary">Small</button>
<button class="pk-btn pk-btn-primary">Default</button>
<button class="pk-btn pk-btn-lg pk-btn-primary">Large</button>

Estados

Los botones incluyen estados de interacción como hover, active y disabled. 

<button class="pk-btn pk-btn-primary" disabled>
  Disabled
</button>

<button class="pk-btn pk-btn-outline-primary is-disabled">
  Disabled class
</button>

Combinación con utilidades

Puedes combinar botones con utilidades de espaciado, sombras, bordes o display.
