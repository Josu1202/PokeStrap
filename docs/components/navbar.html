Navbar

El navbar de PokeStrap permite crear menús de navegación responsivos con soporte para escritorio y dispositivos móviles.

Component Docs

Navbar responsivo

Este componente utiliza clases del framework junto con utilidades flex para lograr un comportamiento adaptable.

Ver ejemplo

Estructura básica

El navbar se compone de un contenedor principal, un bloque superior, un menú de escritorio y un menú móvil. 

<nav class="pk-navbar">
  <div class="d-flex align-items-center justify-content-between w-100">

    <a class="pk-navbar-brand">Brand</a>

    <button data-navbar-toggle>☰</button>

  </div>

  <div class="pk-navbar-menu d-none d-md-flex">...</div>
  <div class="pk-navbar-menu is-hidden d-md-none">...</div>
</nav>

Comportamiento responsive

El menú cambia automáticamente entre escritorio y móvil usando clases d-none, d-md-flex y d-md-none.

Usa JavaScript con data-navbar-toggle para mostrar/ocultar el menú móvil.
