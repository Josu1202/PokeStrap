Instalación

Cómo usar PokeStrap en tu proyecto

Para utilizar PokeStrap solo necesitas enlazar el archivo CSS compilado dentro de tu documento HTML.

1. Enlazar el CSS compilado

Copia el archivo pokestrap.css dentro de tu proyecto y enlázalo en la sección <head>. 

<link rel="stylesheet" href="pokestrap.css">

2. Estructura mínima recomendada

Esta es una plantilla base para comenzar a construir una página usando PokeStrap. 

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi proyecto con PokeStrap</title>
  <link rel="stylesheet" href="pokestrap.css">
</head>
<body>
  <div class="pk-app theme-pokemon-classic">
    <div class="container">
      <h1 class="pk-title-1">Hola PokeStrap</h1>
      <p class="pk-text">Mi primera página usando el framework.</p>
      <a href="#" class="pk-btn pk-btn-primary">Empezar</a>
    </div>
  </div>
</body>
</html>

3. Activar un tema

PokeStrap permite aplicar temas visuales usando clases sobre el contenedor principal. 

<div class="pk-app theme-pokemon-classic">
  ...
</div>
El tema clásico es el recomendado para comenzar, ya que utiliza la paleta principal del framework.

4. Usar componentes

Los componentes utilizan clases con el prefijo pk-. 

<button class="pk-btn pk-btn-primary">Primary</button>
<button class="pk-btn pk-btn-secondary">Secondary</button>
<button class="pk-btn pk-btn-outline-primary">Outline</button>

5. Usar layout y utilidades

Las clases de layout y utilidades usan nombres cortos inspirados en Bootstrap para facilitar la maquetación. 

<div class="container">
  <div class="row">
    <div class="col-12 col-md-6">
      Columna izquierda
    </div>

    <div class="col-12 col-md-6">
      Columna derecha
    </div>
  </div>
</div>

Recomendación

Utiliza pk-app como contenedor principal para aplicar la base visual del framework sin modificar de forma agresiva todo el documento HTML.
