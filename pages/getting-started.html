Inicio rápido con PokeStrap

PokeStrap es un framework CSS personalizado construido con SASS, orientado a la creación rápida de interfaces responsivas con una identidad visual inspirada en Pokémon.

¿Qué incluye?

Sistema de layout

Contenedores, filas, columnas y breakpoints responsive.

Componentes UI

Botones, cards, alertas, formularios, navbar, badges y tablas.

Clases utilitarias

Espaciado, colores, display, flexbox, bordes, sombras y tipografía.

Temas visuales

Tema clásico y variantes Fire, Water, Electric y Grass.

Uso básico

Para usar el framework, enlaza el archivo CSS compilado dentro del documento HTML. 

<link rel="stylesheet" href="pokestrap.css">
