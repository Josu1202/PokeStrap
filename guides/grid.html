Grid

El sistema Grid permite organizar contenido en columnas y filas de forma flexible y responsive.

Ejemplo básico

Columna 1
Columna 2
Columna 3
<div style="display:grid; grid-template-columns: repeat(3, 1fr);">
  <div>Col 1</div>
  <div>Col 2</div>
</div>

Columnas automáticas

Item
Item
Item
Item
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));

Separación (gap)

A
B
C
gap: 2rem;

Conceptos clave

  • Columnas: definen cuántos elementos caben por fila.
  • Filas: se generan automáticamente según el contenido.
  • Gap: controla el espacio entre elementos.
  • Responsive: permite adaptarse a diferentes tamaños de pantalla.
