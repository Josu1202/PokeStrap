Navbar

La barra de navegación permite moverse entre secciones del sitio y organizar enlaces principales.

Ejemplo básico

PokeStrap
Inicio Docs Ejemplos 
<nav class="pk-navbar">
  <a class="pk-navbar-brand">PokeStrap</a>

  <div class="pk-navbar-menu">
    <a class="pk-navbar-link">Inicio</a>
  </div>
</nav>

Navbar fija

Puedes fijar la barra en la parte superior para mantener la navegación siempre visible. 

.pk-navbar-fixed {
  position: fixed;
  top: 0;
  width: 100%;
}

Recuerda agregar espacio superior al contenido para evitar que quede oculto.

Dropdown sin JavaScript

PokeStrap permite crear menús desplegables usando elementos semánticos HTML como details.

Menú
  • Opción 1
  • Opción 2
<details>
  <summary>Menú</summary>
  <ul>
    <li><a>Opción</a></li>
  </ul>
</details>

Estructura

  • pk-navbar: contenedor principal
  • pk-navbar-brand: nombre o logo
  • pk-navbar-menu: grupo de enlaces
  • pk-navbar-link: enlaces de navegación
