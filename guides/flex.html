Flex

Flexbox permite distribuir y alinear elementos dentro de un contenedor de forma flexible y responsive.

Ejemplo básico

Elemento 1
Elemento 2
Elemento 3
<div style="display:flex; gap:1rem;">
  <div>Elemento 1</div>
  <div>Elemento 2</div>
</div>

Dirección

Columna 1
Columna 2
display: flex;
flex-direction: column;

Justificación

Inicio
Centro
Fin
justify-content: space-between;

Alineación

A
B
C
align-items: center;

Conceptos clave

  • Dirección: define si los elementos se organizan en fila o columna.
  • Justificación: controla el espacio horizontal entre elementos.
  • Alineación: controla la posición vertical dentro del contenedor.
