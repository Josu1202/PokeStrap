Spacing

El sistema de espaciado permite controlar márgenes y rellenos para organizar el contenido de forma clara y consistente.

Tipos de espaciado

  • Margin: espacio externo entre elementos.
  • Padding: espacio interno dentro de un elemento.

Ejemplo

Elemento con margin y padding 
<div style="padding:2rem;">
  <div style="margin:1rem; padding:1rem;">
    Contenido
  </div>
</div>

Clases de utilidad

PokeStrap utiliza clases para aplicar spacing de forma rápida sin escribir CSS adicional.

m-2
p-2
<div class="pk-m-2"></div>
<div class="pk-p-2"></div>

Direcciones

  • m: margin
  • p: padding
  • t: top
  • b: bottom
  • s: start (izquierda)
  • e: end (derecha)
pk-m-2
pk-mt-2
pk-p-3
pk-ps-1

Escala de espaciado

  • 0: 0
  • 1: 0.25rem
  • 2: 0.5rem
  • 3: 1rem
  • 4: 1.5rem
  • 5: 2rem
