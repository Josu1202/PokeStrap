Variables CSS

PokeStrap utiliza variables CSS para definir su sistema de colores. Esto permite personalizar fácilmente el tema. 

:root {
  --pk-primary: #ee1515;
  --pk-secondary: #ffde00;
  --pk-accent: #3b4cca;
}
